Satoshi & Bitcoin — a verifiable timeline

Every row carries an evidence grade and, where one exists, a command that regenerates it. Rows we cannot verify are shown too, marked NOT HELD — because a timeline showing only what was found looks complete when it is not.

This timeline is incomplete, and says so on purpose. It currently holds 49 events. The research corpus behind it contains 105 distinct dated events across 55 written entries and 21 sealed archives, and migration into this file is deliberate rather than bulk — each row has to acquire a grade, a source and a reproduction path before it can appear. That corpus is a local research archive and is not itself published, so this number is stated, not linkable. Absence of a row here is not evidence that nothing happened on that date. Applying the same standard to ourselves that we apply to everyone else.
